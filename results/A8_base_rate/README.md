# A8 — base-rate injection sweep

How strongly do the panel models condition on a *stated* prior? One sentence —
"Historically, in this field, the probability of this kind of progress happening is X%." —
is inserted into the base binary system prompt and X is swept over 10/30/50/70/90 % on a
frozen random sample of 500 events (both the original and the perturbed variant, so YES and
NO ground truths are both present). The no-injection baseline is each model's stored base
run on the same items, never regenerated.

    sample.json       500 event ids, seed 8, per-event metadata
    prompts.md        exact system prompt per X (sha256) and decoding per model
    raw/<model>.jsonl inference shards, one record per (x, id, task), resumable
    outputs.jsonl     concatenation of the shards (regenerated by a8_analyze.py)
    tables/           curves_common.md (primary), curves_all_valid.md, curves.csv,
                      slopes.md/.csv, partition_slopes.md, coverage.md, cost_estimate.md
    figures/          <metric>_panels.png, <metric>_overlay.png, slopes.png
    results.md        narrative results;  response_A8.md  the reviewer response
    MANIFEST.json     models, snapshots, dates, seed, prompt hashes, costs, git SHA

Regenerate everything downstream of raw/ with `bash results/A8_base_rate/run_all.sh`.
Inference: `python scripts/a8_run.py --model <key>` (see a8_common.MODELS); GPT-OSS 20B
is served locally first with `bash scripts/serve_gptoss.sh`.
