# A5.3b -- performance by editorial latency (received -> online, Nature and Science)

Editorial latency = Crossref online-publication month minus the manuscript-received month deposited by the publisher. Nature and Science deposit received dates; Cell (Elsevier) does not, so this covers 3,740 Nature and Science events. This measures how long the result sat in peer review, a different construct from A5.3.

Cells are `value [95% CI] (n observations)`; binary n counts the real and perturbed question separately. Cells below n=20 are printed as `n<20 (n)` with no point estimate. `p (perm)` is a 10,000-draw permutation test shuffling stratum labels across events; `p (Holm)` is Holm-Bonferroni corrected across every model x partition x task test in this stratification.
