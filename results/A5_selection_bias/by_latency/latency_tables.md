# A5.3 -- performance by publication latency (months publicly observable before the journal version)

Latency = Crossref online-publication month of the journal version minus CUSP's first-observable month (`publication_date`, which the build pipeline set to the earliest date found across Crossref, bioRxiv, medRxiv, Semantic Scholar and Europe PMC). Computable for 4,326 journal events (Nature, Science, Cell; both halves), i.e. every journal event whose DOI resolved at Crossref on 2026-09-25. arXiv events have no journal version and are excluded by construction; leaderboard items have no paper.

0 mo means no earlier public trace was found: the first observable date is the journal's own online date. Larger values mean a preprint or other public record predated the journal version by that many months.

Cells are `value [95% CI] (n observations)`; binary n counts the real and perturbed question separately. Cells below n=20 are printed as `n<20 (n)` with no point estimate. `p (perm)` is a 10,000-draw permutation test shuffling stratum labels across events; `p (Holm)` is Holm-Bonferroni corrected across every model x partition x task test in this stratification.
