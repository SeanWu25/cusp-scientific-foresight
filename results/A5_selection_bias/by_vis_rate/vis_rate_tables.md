# A5.2b -- performance by citation rate (citations per month since first observable, whole corpus)

Citation rate = citations / max(1, months from first-observable month to the 2026-09-25 snapshot), for the same 5,513 events as A5.2. Quartile edges: Q1 <= 0.96, Q2 <= 1.83, Q3 <= 3.94, Q4 > 3.94 citations per month.

This is the age-adjusted visibility measure and the one we treat as primary: it puts a 2026 extension event and a 2024 event on the same footing.

Cells are `value [95% CI] (n observations)`; binary n counts the real and perturbed question separately. Cells below n=20 are printed as `n<20 (n)` with no point estimate. `p (perm)` is a 10,000-draw permutation test shuffling stratum labels across events; `p (Holm)` is Holm-Bonferroni corrected across every model x partition x task test in this stratification.
