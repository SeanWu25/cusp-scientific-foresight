Pre = publication month ≤ cutoff month, post = publication month > cutoff month. Same events in all four conditions; retrieval-failed rows dropped; paired normal 95% CIs. GPT-4o and LLaMA 3.3 have no pre-cutoff events in the subset (LLaMA 3.3's unrestricted run was generated 2026-10-05). Cells with n < 20 suppressed.
