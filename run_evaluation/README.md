# Analysis & Visualization

Scripts that reproduce the figures and tables in the CUSP paper from model
evaluation results (JSON files produced by `scripts/eval.py`).

| Script | Output | Description |
|--------|--------|-------------|
| `compare_models.py` | `comparison_figures/fig1–fig14.{pdf,png}` | Multi-model comparison figures: leaderboard, radars, area heatmap, response bias, cutoff-temporal analysis, date-prediction deep-dives, calibration, FRQ overview |
| `make_latex_tables.py` | `tables/table1–table7*.tex`, `tables_all.tex` | Publication LaTeX tables: main results, binary bias, date statistics, per-area breakdowns, pre/post-cutoff splits, calibration |
| `compare_web_search.py` | `figures_web_search_comparison/*.{pdf,png,tex}` | Web-search ablation on the 500-question matched subset: baseline vs. web search vs. web search + cutoff |
| `make_web_search_cutoff_table.py` | `figures_web_search_comparison/table_web_search_cutoff.tex` | LaTeX table extending the web-search comparison with cutoff-conditioned columns |

## Usage

```bash
# Figures (reads per-model result JSONs from a directory)
python compare_models.py \
    --results frq_results/ \
    --benchmark path/to/CUSP_final.jsonl \
    --output-dir frq_results/comparison_figures/

# Tables
python make_latex_tables.py \
    --results frq_results/ \
    --benchmark path/to/CUSP_final.jsonl \
    --output-dir frq_results/tables/

# Web-search ablation (expects result JSONs under ./frq_results/)
python compare_web_search.py
python make_web_search_cutoff_table.py
```

The benchmark file is downloadable from
[huggingface.co/datasets/SeanWu25/CUSP](https://huggingface.co/datasets/SeanWu25/CUSP).
Model result JSONs are generated by `scripts/eval.py`; the filenames each
script expects are listed in its `MODEL_REGISTRY` / `CONDITIONS` block at the
top of the file.

Requirements: `matplotlib >= 3.5`, `numpy`, `scipy` (see repository
`requirements.txt`).
