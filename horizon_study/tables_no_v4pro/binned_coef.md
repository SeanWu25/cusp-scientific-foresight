# Horizon entered as bin dummies — coefficients of the reviewer-4 model

`g(E[Y_imc]) = β0 + Σ_b β_b·1[H_im ∈ b] + β2·R_c + Σ_b β3_b·1[H_im ∈ b]·R_c + u_i + v_m`, reference bin = the shortest horizon. Bins with fewer than 30 items are pooled upward, so the last bin can be wider than the scheme. Post-cutoff only.

Two estimators per fit. **GLMM** = the equation as written (crossed random intercepts for event and model, Laplace). **Stratified** = event fixed effects + model fixed effects (conditional logit for binary/MCQ; event-demeaned OLS with event-clustered SE for date/FRQ), which identifies the bin contrasts without the random-effects assumption. Omnibus: GLMM likelihood-ratio (Laplace, approximate) or stratified Wald that the bin block is zero.

Reading rule: the *pattern* across bins is the identified quantity. Because h = calendar − cutoff, a smooth linear drift across bins cannot be separated from calendar drift by either estimator; departures from linearity (a knee, a plateau, a collapse) can.
